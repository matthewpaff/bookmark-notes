# Contributing

Keep changes small, useful, and dependency-free. Run the standard-library tests
with `python -m unittest discover -s tests -v`. For interface changes, check narrow
screens, keyboard focus, labels, and the JavaScript-disabled workflow.

Preserve HTML escaping, parameterized queries, form tokens, host validation, and
transactional writes. Never commit personal bookmarks, databases, or credentials.
Use actual development dates and credit third-party material where applicable.
